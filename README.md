# 英语口语小达人 🎤

专为中国小学生（6–12 岁）设计的**英语口语练习网站**：单词、句子、情景对话、看图说话挑战，边玩边学，大声开口！

## ✨ 功能

| 板块 | 内容 |
|------|------|
| 🏠 首页 | 卡通吉祥物、每日任务推荐、各练习入口 |
| 📖 单词乐园 | 7 大类 73 个单词（动物/食物/颜色/数字 1–20/家庭/学校/身体），带音标、中文、emoji |
| 💬 句子跟读 | 5 个主题 25 个常用句子（打招呼/自我介绍/学校生活/家庭/食物） |
| 🎭 情景对话 | 5 组生活对话（见面/自我介绍/餐厅/买文具/问路），可点气泡听发音，支持**角色扮演** |
| 🎮 趣味挑战 | 7 个看图说话场景，识别关键词打分 |
| 🏆 我的成就 | 总星星、练习统计、连续打卡天数、6 枚徽章，数据保存在浏览器本地 |

**语音技术**（全部浏览器原生，无需服务器）：
- 🔊 听一听：`speechSynthesis` 美音朗读，语速放慢适合孩子
- 🎤 跟我读：`SpeechRecognition` 识别 → 单词重合度模糊打分（0–100 分，1–3 星，阈值宽容以鼓励为主）
- 3 星触发撒花动画 🎉（纯 CSS/JS 实现）

## 📁 文件结构

```
english-speaking/
├── index.html   # 页面结构（单页多视图 + 底部导航）
├── styles.css   # 全部样式（暖色系、大圆角、手机优先，无框架）
├── data.js      # 所有学习内容（单词/句子/对话/挑战/徽章）——想加内容只改这里
├── app.js       # 全部交互逻辑（视图切换、语音、打分、成就、本地存储）
└── README.md    # 本文件
```

无构建工具、无外部 CDN 依赖（系统字体），国内访问速度快。

## 🚀 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `english-speaking`），保持公开（Public）。
2. 把本目录下的 5 个文件上传到仓库根目录（网页端 Add file → Upload files，或用 git push）。
3. 进入仓库 **Settings → Pages**：
   - Source 选择 **Deploy from a branch**
   - Branch 选择 **main**（或 master），文件夹选 **/(root)**，点 Save。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/english-speaking/` 即可使用。

> 💡 也可以直接用任意静态托管（Gitee Pages、Netlify、Vercel、OSS 静态网站等）部署，解压即用。

## 💻 本地预览

双击打开 `index.html` 即可；推荐用本地服务预览语音功能更稳定：

```bash
cd english-speaking
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## ⚠️ 浏览器建议

- **推荐 Chrome / Edge**：语音识别（🎤 跟我读）依赖浏览器的 SpeechRecognition，Chrome 支持最好。
- Safari / 微信内置浏览器：可正常使用「🔊 听一听」和浏览全部内容；若不支持语音识别，页面会给出中文提示。
- 首次使用麦克风时，浏览器会请求麦克风权限，请点「允许」。

## 🔧 自定义内容

所有学习内容都在 `data.js` 里，按现有格式添加即可，例如加一个单词：

```js
{ en: "lion", phon: "[ˈlaɪən]", zh: "狮子", emoji: "🦁" },
```

学习记录保存在浏览器 `localStorage`（键名 `speakFunStatsV1`），「我的成就」页可一键清空。
